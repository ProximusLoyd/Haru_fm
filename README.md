# Haru_fm
A file manager that can help you edit text/code/config along with media playing and viewing capabilities

It have options for syntax highlighting and file share capabilities if required

__INSTALLATION__ 

Desktop editions

Download it from  :- https://github.com/ProximusLoyd/Haru_fm/releases

INTEL / AMD/ ARM  [ ARM64-8 , ARMeabi-v7 , x64 & x32/ i686 ]

- Linux (appimage for both 64 and 32 bit versions of intel/amd ). 
   Install linux builds ( .AppImage ) aarch64(ARM) , x62 bit version or x32/i686 version accordingly 

- Windows (exe for both 64 and 32 bit versions of intel/amd). (most compatible in Windows 10/11)
   Install windows 10/11  builds ( .exe ) aarch64(ARM) , x62 bit version or x32/i686 version accordingly

Use haru_font_installer.apk for additional fonts for languages other than English , Japanese , Arabic , Hindi and Sanskrit. For artistic font types too .
From here:- https://github.com/ProximusLoyd/font_installer-for-Haru_fm/releases/tag/font-installer-v1.1.2
